OpenRA MCP

2026.06 · 预印本Jun 2026 · preprint

一句话指挥 RTS 战斗的 AI 战术副官，并把指令翻译能力蒸馏到一个能在本地运行的 0.5B 小模型。

An AI co-pilot that runs RTS battles from one sentence, with its command translation distilled into a 0.5B model that runs locally.

玩家player 南北夹击敌总部pincer the enemy HQ from north and south
↓ LLM / Qwen2.5-0.5B
{ "intent": "pincer", "left": { "kind": "group", "name": "north" }, "right": { "kind": "group", "name": "south" }, "target": { "kind": "named", "name": "enemy_fact" } }
↓ 解释器 → OpenRA 引擎逐帧执行interpreter → OpenRA engine, tick by tick
17个 MCP 工具MCP tools
10/10能力场景通过capability scenarios
99%小模型意图识别small-model intent accuracy
0.8GB本地运行显存to run locally
展开详情More
  • 人在回路：玩家保留战略判断，AI 只做执行层副驾驶；LLM 不进逐帧循环，循环交给守护进程，指令可审计。
  • 工具设计：17 个工具 + 2 个小队原语覆盖钳形、佯攻、路线约束、分时进攻等 10 类战术；字段全部枚举约束，LLM 只填语义，不算坐标。
  • 小模型：用大模型生成约 1,000 条「指令 → JSON」数据，QLoRA 微调 Qwen2.5-0.5B，输出 100% 合法、意图识别 99%，不再依赖付费 API。
  • 迭代发现：v1–v3 分数不低，但对准的是已废弃的指令格式，约 80% 输出引擎不认，v4 改为对准真实格式；数据类别配比是关键，常见类上限约为少见类 2 倍时两头兼顾。
  • Human-in-the-loop: the player keeps strategy, the AI handles execution. The LLM stays out of the per-tick loop, a daemon runs it, and every order is auditable.
  • Tool design: 17 tools + 2 squad primitives cover 10 tactics (pincer, feint, route constraints, timed assaults). Fields are enum-constrained; the LLM fills in meaning, never coordinates.
  • Small model: ~1,000 command → JSON pairs generated with an LLM, QLoRA-fine-tuned Qwen2.5-0.5B: 100% valid JSON, 99% intent accuracy, no paid API.
  • What iterating taught me: v1–v3 scored well against a deprecated format, so ~80% of outputs were rejected; v4 targets the live format. Class balance is the key lever: cap the common class at ~2× the rare ones.

小模型数据为 v4 版本、100 条留出指令评测；完整命令逐字一致率 50%。Small-model figures: v4 on 100 held-out commands; 50% exact match on the full order.

  • 传播：63% 的用户在 App 内置浏览器里打开（多为分享链接），豆瓣是最大的外部来源，约 5,400 人。
  • 认真程度：完整版占 63%，作答时长中位数 4 分钟，GA 投入率 69%。

  • Spread: 63% of users opened it in an app's built-in browser (mostly shared links); Douban was the largest outside source, ~5,400 users.
  • Engagement: 63% chose the full version, median session 4 minutes, GA engagement rate 69%.
  • Retrospective: traffic-billed hosting got too expensive; after shutdown, daily completions fell from 3,745 to 189. Free static hosting with a thin back end would have done. Also, 35.2% of results were one emperor, so the matching needs recalibrating with the per-answer data.

  • Auto-filing: one tap to save; the cloud summarises and extracts mood, energy and people, and the plugin writes a note with timeline, photo wall, people graph and mood heatmap.
  • Stack: Cloudflare Worker + D1/KV + DeepSeek + Obsidian plugin, all on free tiers. Input is Telegram today; a channel native to mainland users is next.
